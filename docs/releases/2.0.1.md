# 2.0.1 发布说明

发布日期：2026-10-24；版本标签：`v2.0.1`。

本版本是 [2.0.0](2.0.0.md) 的跨平台构建与验收修订，保留 `v2.0.0` 及更早版本标签。

- 补齐根目录依赖锁中遗漏的 Rollup、esbuild 等平台可选包及完整性信息，支持 Linux、macOS、Windows 的干净安装。包版本沿用现有独立前端锁文件，没有升级第三方依赖版本。
- 增加根目录与独立前端依赖锁的跨平台回归检查，防止在 Windows 安装后重新生成锁文件时遗漏其他平台构建包。
- 调整隔离容器验收：公开就绪探针保持最小状态响应；依赖详情从验收自行创建的容器内部读取，继续核验数据库结构和模型配置状态。
- 为容器诊断结果增加独立标识与回归检查，避免将运行日志误作检测结果；验收失败报告提供源码位置。
- 项目、当前 React 前端及后端版本统一为 `2.0.1`。

2.0 业务功能与升级路径见 [2.0.0 发布说明](2.0.0.md)。本修订不执行生产部署或业务数据库迁移，也不增加外部模型调用。

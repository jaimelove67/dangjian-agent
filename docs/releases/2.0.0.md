# 2.0.0 发布说明

发布日期：2026-10-24；版本标签：`v2.0.0`。

本版本以原仓库 `master` 的 `b190fcb9464c2fb2a9116b469b5a0a4d2a4cd274` 为基线，将当前 React 业务前端与 FastAPI 后端纳入统一版本。前端位于 `frontend/`，后端位于 `backend/`；原有 Git 历史及 `v0.5.0` 标签保留。

## 主要变更

- 按平台、学校、院系、支部和本人范围提供工作台、导航与业务授权。
- 完善账号编辑、密码修改申请、一次性审批授权、会话撤销和安全审计。
- 补齐会议、党员发展、组织业务、学习计划、校级任务、课程活动和年度考核的登记、版本核验、独立审核及归档流程。
- 支持个人原件、发展材料、知识文档版本及引用追溯；填写建议经用户确认后仅填入空白项，保留人工内容。
- 增加受控加密备份及隔离恢复任务，按实际执行状态和校验结果呈现。
- 统一正式系统文案，兼容已有浏览器工作区中的系统预置文本。
- 统一项目及后端接口版本为 `2.0.0`，补充适配当前目录结构的前后端 CI。

## 升级说明

1. 原仓库根目录的 FastAPI、迁移、配置及服务端脚本在本版本移至 `backend/`；当前 React 位于根目录 `frontend/`。部署路径、容器构建上下文和 CI 应按新目录使用。
2. 现有数据库先确认目标并备份，再根据 [迁移说明](../../backend/migrations/README.md) 升级到 `031_backup_jobs`。本次源码发布不执行数据库迁移或生产部署。
3. 凭据与业务原件由实际部署环境配置和保存；源码版本不包含本机 `.env`、账号数据、备份或联调临时产物。
4. 后端模式设置 `VITE_DATA_MODE=live`，以实际认证、租户及组织授权为准。单独前端的浏览器工作区不提供服务端多用户安全边界。

功能补齐与联调记录见 [2026-10-24 联调报告](../integration-check-2026-10-24.md)：后端完整回归 1,190 项通过，覆盖率 85.69%；七角色页面权限、浏览器业务闭环、限定合成模型引用、加密备份及隔离恢复均按报告范围验证。

后续正式文案更新通过前端及开发入口 89 项、文档解析 13 项、Sites 兼容 4 项及生产构建；本地前端八类身份、86 个可访问页面和重点弹窗完成文案检查。该轮没有重新执行后端全业务流程，也没有增加外部模型调用。

以上为本机隔离环境验证。学校制度、模型准入、真实材料质量、实际运维配置和生产上线仍按对应业务与部署要求验收。

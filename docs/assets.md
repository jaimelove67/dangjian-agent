## 提取与图标

- `profile-photo.png`、`course-1.png` 至 `course-8.png`、`activity-1.png` 至 `activity-4.png` 是用户源图中相应可见素材的裁切，保持原图主题。由于总览图本身分辨率有限，缩略图清晰度有限，正式视频课程和活动媒体应替换成原始素材。
- 品牌标记与 favicon 使用官方 Material Design Icons `hammer-sickle` 图标数据，界面图标使用 Phosphor Icons，没有手绘图像替代。
- 字体使用系统 `Microsoft YaHei / PingFang SC / Noto Sans CJK SC / Arial`，页面不依赖外部字体服务。
- 红色选中态、边框、组织树连接线、统计进度条由 CSS 实现；数据图表使用 Recharts，未以截图代替可交互图表。

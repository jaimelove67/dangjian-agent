# 刷新与业务操作位置检查

日期：2026-10-29。

用户指出“我的学习 → 我的积分”的刷新单独位于卡片左侧。本轮在修改前采集本地页面截图，并检查共用工具栏及相关角色页面；修改范围为按钮布局和内容分组。

## 发现与修正

1. **我的学习：已修正。** 积分页没有筛选项，刷新却单独占一行，并且比说明、表格更靠左。现在说明在左、刷新在右，与表格对齐；主题党日和管理课程列表的搜索、状态筛选与操作也分别成组。[修改前](screenshots/action-layout-before-credits.png) / [修改后](screenshots/action-layout-credits.png)。
2. **学校业务与备份：已修正。** 公示管理、角色申请等页面的刷新移入标题操作组；备份页的刷新与创建操作也归入标题栏。任务页保留逾期筛选，学校参数页移除无关的逾期筛选。
3. **组织业务、学习计划、考核、制度文件：已修正。** 原工具栏没有横向边距，所有按钮与筛选挤在左侧。新增明确的筛选区和操作区，对齐表格；刷新与次要操作在前，主要办理操作在后。考核标签内的操作仍放在相应内容区。[组织业务修改后](screenshots/action-layout-member-business.png)。
4. **全部公示弹窗：已修正。** 刷新原位于分页下方，长列表中需要滚动才能找到。现在位于顶部搜索右侧，窄屏下与搜索一起换行。[修改后](screenshots/action-layout-publications.png)。首页公示卡片不额外增加刷新入口。

## 验证

- 浏览器覆盖 1440、1024、768、390、360 像素宽度，检查工具栏与表格两侧对齐、按钮处于视口范围内，并查看代表性桌面和窄屏截图。[积分页窄屏](screenshots/action-layout-credits-mobile.png)。
- 点击并确认六类刷新发出对应查询：积分、公示业务记录、考核工作区、学习计划、制度文件和备份任务。
- 检查组织业务各标签权限、主要按钮、筛选更新及原有回调；未发现本轮改动导致的具体回归。
- `npm test`：前端 116 项、开发配置及依赖检查 5 项通过。
- `npm run build`：通过。仍有现有的较大分包提示。
- `npm run test:sites`：4 项通过。

真实模式页面使用隔离浏览器和拦截的接口数据检查布局及请求，未连接生产业务服务、未提交业务写入；这些结果不作为生产后端验收。完整本地截图和几何检查记录保存在 `tmp/action-layout-qa/`。

页面级刷新已处于合理标题栏的位置（平台工作台、系统运维概览、账号与权限等）以及记录行内操作均未作统一挪动。后续新增列表沿用已记录在 `AGENTS.md` 的位置约定。

# 材料填写建议

个人账号从“个人材料 → 提交材料”选择原件。组织办理人从“党员发展 → 材料清单 → 登记材料”选择可选原件。选文件后展示明确字段及原文依据，点击“采用建议填入空白项”才填表，最后确认提交。个人材料可填标题、类型和原文标注的材料说明，发展材料可填材料类型。

姓名、文档日期、出具单位仅供核对；组织收到日期、档案关联、核验结论及发展阶段由人工办理。手填值不会被建议覆盖，更换文件时清除仍未人工修改的已采用建议。预览不保存文件、材料、全文审计或人员信息；最终提交沿用原件存储、租户及组织范围校验，发展材料仍为待核验。

真实模式支持本地读取 TXT、MD、DOCX（含表格文字）、含文字的 PDF。当前使用明确标题及标签规则，不调用外部模型，无法识别的字段留空。图片、扫描 PDF、损坏文档和提取错误均提示手动填写，仍可提交原件。演示模式不伪造提取成功。

预览接口：`POST /api/v1/member/self/materials/preview`、`POST /api/v1/member-full/profiles/{profile_id}/materials/preview`，仅接收 multipart `file`。前者使用当前账号的有效本人档案，后者要求发展办理权限及档案范围。返回 `status`、`fields`、逐字段 `evidence`、`notes`，响应禁止缓存。

原有发展材料 `/materials/scan` 兼容 DOCX、TXT、MD 原件，以及人工确认的 `file_version`、`submit_date`，默认关闭云识别。发展原件下载为 `GET /api/v1/member-full/materials/{material_id}/file`，校验租户、组织范围与材料敏感等级，并记录下载审计。

解析受上传大小、DOCX 解压量与压缩比例、PDF 前 40 页及正文 80000 字上限约束。截断会提示核对完整原件。提取规则的覆盖程度不代表文档真实性、完整性或审核结果。

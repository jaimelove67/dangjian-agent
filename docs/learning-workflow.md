# 党建学习业务

## 入口与角色

教师党员、学生党员和入党申请人从侧栏“我的学习”或首页学习区进入同一页面。首页显示本人学习中、已完成课程及累计积分，并可直达课程或积分记录。本地和真实模式保留一致的入口、课程、测评、活动和积分操作。

学校管理员通过“学习教育 → 学习课程与活动”维护课程；院系、书记和组织员只能维护后端授权组织中的内容。年度中心组计划及原有学习任务继续使用原流程，平台管理员继续使用独立运维首页。

## 课程与学习记录

课程窗口采用单列沉浸阅读布局，顶部为“学习内容、课程测评、本人笔记”，底部固定返回及当前分区操作。分区隐藏时保留本次答案和未保存笔记，测评提交按钮通过本课程表单关联执行原生必填校验。已完成课程仍可查看正文、成绩及维护本人笔记；有维护权限的组织人员另有组织学习进度入口。

资料份数按课程实际正文与播放内容计算，只有一份时禁用前后切换，不以参考图的份数补造文件。文本按原文的标题及编号呈现，不渲染原文HTML；尚未接入的Word/PDF课程附件关联不因此视为已经实现。

- 管理人员编制课程草稿，再单独确认发布；课程至少包含视频或测评，视频必须填写可访问地址和真实时长。
- 学员先开始本次学习，再保存本人笔记、观看视频或参加测评。笔记可以单独修改或清空，不改变完成状态和积分。
- 阅读区提供“记录笔记”入口，切换后聚焦笔记输入。笔记按课程内实际资料章节分别保存，切换章节或分区保留未保存草稿。本人已保存笔记的课程目录、章节及笔记入口显示“有笔记”；草稿显示“未保存”，清空并保存后移除对应标记。保存状态在输入框上方显示，课程目录随保存结果刷新。
- 视频按正常播放保存进度，重复观看同一区间不重复增加有效覆盖。沿用现有后端的完成判定：视频有效覆盖达到90%，并通过课程配置的测评（若有）后完成。
- 切换分区、切换资料或关闭窗口时暂停播放并保存当前位置；已有保存请求尚未结束时，仅排队补存最新暂停位置。排队状态与原课程及账号回调绑定，防止新课程接收旧播放位置。
- 测评检查完整作答、合格分数和次数上限；真实模式由后端判分。提交前的学员题目只包含题号、题干与选项，提交后在本人进度中保存本次逐题作答、正确答案与组织编制的解析，页面展示成绩、答题对错和解析；未通过时可在剩余次数内重答。历史成绩缺少原作答时只展示可确认的标准答案，并标注原作答未保存；组织没有编制解析时如实说明。
- 已完成课程重复提交不会重复增加积分。学员可以查看已完成记录、成绩和自己的笔记。
- 资源不可播放、接口不可用或组织选项加载失败时提供实际错误及恢复入口，不以本地内容替代真实服务结果。

本地课程保留原有专题目录，尚未配置视频的专题使用阅读导读和学习准备测评，不展示虚构播放记录。用户以前保存但无法确定归属的全局 `learning` 数据不自动转成某个账号的正式成绩或积分。

## 活动报名

活动保留开始时间、报名截止、人数上限和完成积分。有效报名可在截止前取消，重复报名不占用重复名额。实际出席由其他有权限的组织人员在活动开展后核验；报名本身不产生完成积分。

## 本人笔记接口

`POST /api/v1/education/offerings/{id}/notes` 接受 `{"note": "本人学习体会", "material_id": "reading"}`，每份资料最多5000字。`material_id` 为 `reading`（导读或说明）或 `lesson`（课程视频），后端检查课程实际存在该资料；省略时按 `reading` 办理，兼容原有接口。进度JSON的 `material_notes` 分别保存章节笔记，`note` 保留首份阅读资料笔记以兼容旧记录，无需数据库迁移。

后端根据当前登录账号和租户寻找学习记录，不接受用户编号、成绩、积分等附加字段。课程详情及进度只返回当前账号的笔记和测评复盘（`exam_review`），管理端学员名单不返回这些正文，审计不记录笔记或答案内容。试题的可选 `explanation` 最多5000字；编课时每行原格式末尾可加 `| 解析：说明`，旧格式继续有效。

## 数据与验证

真实模式复用 `/education/offerings`、`enroll`、`heartbeat`、`exam`、`credits`、`cancel` 和 `attendance` 等既有接口。新笔记接口与原进度更新均使用学习记录行锁；本地学习记录独立保存在 `education` 字段，按租户、账号及组织范围选择，不复用其他人的学习进度。

本轮验证包括前端回归、后端SQLite隔离工作流、本地浏览器完整交互及真实页面连接内存SQLite测试后端的HTTP流程。实际HTTP流程覆盖编课发布、笔记、测评与积分、账号隔离，以及本机生成测试视频的正常播放和进度记账。没有连接生产数据库、配置外部课程平台或执行部署；正式课程视频和试题仍须由所属组织维护。

评测复盘及章节笔记的浏览器回归入口为 `node scripts/check-education-browser.mjs`。它连接本地开发前端与本机CDP浏览器，创建隔离浏览器上下文，覆盖记录笔记、草稿切换、保存与清空标签、关闭重开、必填校验、未通过后重答、通过后的答案解析，并在结束时清理测试上下文。可通过 `EDUCATION_TEST_ORIGIN`、`EDUCATION_TEST_CDP` 指定本机地址；`EDUCATION_TEST_ARTIFACT_DIR` 指定桌面与手机尺寸截图的输出目录。

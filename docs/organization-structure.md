# 真实组织架构展示

核对日期：2026-10-24。

原页面将架构图限制为 `!IS_LIVE`，真实模式即使收到组织列表也只能显示表格。原接口只返回 `id/name/org_type`，缺少重建层级所需的父节点；右侧还有演示模式的固定统计值。

现在 `/api/v1/member/org-units` 增加可空 `parent_id`，沿用原有租户和组织范围校验，仅当父节点也在同一可见结果中时输出其 ID。无需数据库迁移，不增加角色权限、不补查范围外祖先。

React 在“组织与党员 → 组织结构与负责人 → 党组织架构”使用真实返回数据构树；院系账号从本院开始，支部账号只显示本支部。缺失父节点、自环和循环父链不会补造上级或造成无限递归。搜索保留实际祖先关系，统计按完整授权列表的类型计算；加载失败提供重试，不回退演示数据。真实模式未加载的党员人数显示“以授权名册为准”。

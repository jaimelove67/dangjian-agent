二、引用溯源卡与拒答态

这是本项目区别于普通聊天机器人的核心界面。把后端五大核验项（引用编号有效性、条款真实性、文件时效、引用完整性、无依据长回答检测）可视化出来，用户才看得到价值。拒答态必须单独设计，不能只做「正常回答」一种状态。

## 📦 核心模块

### 1. 基础设施层
- **FastAPI应用**: 完整的应用骨架，生命周期管理
- **Redis缓存**: 连接管理，统一缓存接口
- **配置管理**: 多租户配置，环境变量加载
- **健康检查**: 3个端点（基础/就绪/存活）
- **结构化日志**: JSON格式，支持追踪ID

### 2. 模型服务层
- **模型注册表**: 注册/查询/健康检查
- **模型路由器**: 按数据级别和任务类型路由
- **出网闸门**: 4级数据级别拦截（公开/内部/敏感/涉密）
- **模型服务**: 统一生成/向量化接口
- **模型提供者**: Qwen LLM、Embedding、Reranker

### 3. 检索层
- **向量检索**: pgvector余弦相似度
- **关键词检索**: PostgreSQL全文检索
- **混合检索**: RRF融合算法
- **重排器**: 交叉编码器精排
- **无依据判定**: 阈值判定
- **检索服务**: 整合所有检索功能

### 4. 问答层
- **问答服务**: 完整问答流程
- **问答API**: REST接口，权限控制
- **拒答机制**: 无依据时明确说明
- **引用管理**: 自动提取和核验

### 5. 评测层
- **评测样本**: 检索20条 + 问答20条
- **评测脚本**: 自动化评测框架
- **评测指标**: Recall、MRR、Precision、拒答准确率

## 🎯 技术亮点

### 1. 架构设计
- **分层清晰**: API → Service → Repository
- **依赖注入**: FastAPI Depends + Protocol抽象
- **单例模式**: 全局服务实例管理
- **策略模式**: 可插拔的检索策略

- **出网闸门**: 按数据级别自动拦截外部模型

- **权限控制**: 基于角色的访问控制

- **数据库索引**: 向量索引 + 全文检索索引

- **缓存机制**: Redis缓存配置和会话
- **异步IO**: 全异步数据库和HTTP调用

### 4. 算法实现
- **RRF融合**: Reciprocal Rank Fusion
- **余弦相似度**: pgvector向量检索
- **全文检索**: PostgreSQL ts_rank
- **交叉编码器**: DashScope重排模型

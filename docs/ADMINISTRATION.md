# 管理工作台与党员自助指南

更新日期：2026-10-11。依据当前本地工作区（含未提交的管理员工作台代码），不代表远端或生产环境已交付。操作前按[运行指南](RUNNING.md)准备依赖，并迁移至 `009_admin_workspace`。真实账号、组织和学校验收仍需另行完成。

## 平台管理员工作台

仅 `system_admin` 可进入以下页面，数据范围来自登录态的当前租户，不接受客户端指定其他单位。

| 页面 | 主要操作 | 边界 |
| --- | --- | --- |
| `/admin` | 当前单位账号/组织/制度统计、异常项和最近操作 | 统计实际记录；不读取私有问答或材料原件 |
| `/accounts` | 搜索、分页、开户、姓名/角色/组织编辑、启停与密码重置 | 禁止停用自己或修改自己的角色；已关联档案的账号不能直接调整角色/组织 |
| `/organizations` | 登记学校→院系→支部，修改名称和查看账号计数 | 不移动/删除组织，不跨租户登记；名称变更同步当前单位名册 |
| `/audit` | 按账号、日期、操作和对象筛选，分页查看详情 | 只读；日期边界按北京时间计算 |
| `/system` | 运行/就绪详情及单位检索和业务配置 | 校级、院系管理员也不能查看平台详情；就绪不是业务验收 |

平台管理员默认首页为 `/admin`，明确的登录回跳地址仍保留。其他角色使用原业务入口，访问无权限页面转到 `/forbidden`，不能因此取得管理数据。

首次开户前须有有效组织。学校/院系管理员分别绑定学校/院系，支部书记、组织员、普通党员及申请人绑定支部。用户名全局唯一；密码至少8字符且不超过72个UTF-8字节，页面要求确认密码。密码保存bcrypt哈希，创建结果不返回明文。

组织管理可以登记当前单位层级。若旧初始化管理员缺少所属租户记录，首次学校登记只补齐当前登录单位；这不允许任意新建其他学校租户。开发脚本需要预先存在的有效组织，没有自动创建初始租户/组织的通用脚本。开发初始化示例见运行指南；不要用删表工具解决缺组织问题。

账号角色、组织、状态或密码发生安全变更时更新持久会话版本 `auth_version`，旧访问和刷新令牌失效。重新启用不会恢复旧登录。姓名修改不属于权限变更。管理员重置自己的密码后退出并重新登录。

## 本人档案与私有材料

普通党员仅使用 `/my-archive`、`/my-materials`、`/ask`。不能进入知识库目录或组织管理，制度问答仍检索获准公共政策与本校资料。

1. 组织人员在 `/members` 选择正确台账，打开“账号与个人提交”，明确关联同一组织的有效普通党员账号。不能依姓名推断，也不能直接覆盖不同账号的既有关系。
2. 党员登录后只读本人档案。未关联或组织已失效时，页面提示联系组织人员，不能提交到他人档案。
3. 在个人材料页填写标题、类型、说明并上传原件。支持PDF、DOCX、TXT、MD、PNG、JPG/JPEG，默认上限10MB，由 `MAX_UPLOAD_SIZE` 配置。提交使用稳定重试编号，同一提交重试不重复保存；失败时保留表单以便修正。
4. 党员可查看提交记录、下载本人原件；组织人员从授权名册查看和下载。提交记录与组织登记的已具备材料分开，提交不等于核验通过或阶段变更。

私有原件保存于数据库 `member_materials`，不进入制度知识库、向量化、外部模型或管理员概况。部署备份须覆盖该表；知识库原始制度文件下载仍未实现，不要混淆两类原件。

## 接口入口

所有路径前缀为 `/api/v1`，需要已登录身份；具体输入和错误以schema与服务端检查为准。

| 接口 | 用途 |
| --- | --- |
| `GET /admin/workspace` | 当前单位真实管理概况 |
| `GET /admin/users`、`POST /admin/users` | 查询或创建账号 |
| `PATCH /admin/users/{identifier}` | 修改姓名、角色和组织 |
| `PATCH /admin/users/{identifier}/status` | 启停账号 |
| `POST /admin/users/{identifier}/password` | 重置密码、吊销旧登录 |
| `GET /admin/org-units` | 开户时可用组织选项 |
| `GET/POST /admin/organizations`、`PATCH /admin/organizations/{identifier}` | 查询、登记和维护组织 |
| `GET/PATCH /admin/config`、`GET /admin/audit-logs` | 单位配置与审计 |
| `GET /admin/health`、`GET /admin/health/ready` | 平台管理员运行/就绪详情 |
| `GET /member/self/archive` | 本人档案 |
| `GET/POST /member/self/materials`、`GET /member/self/materials/{material_id}/file` | 本人材料及原件 |
| `PUT /member/roster/{profile_id}/account` | 组织人员关联本人账号 |
| `GET /member/roster/{profile_id}/materials` | 授权档案提交记录 |
| `GET /member/roster/{profile_id}/materials/{material_id}/file` | 组织人员下载授权原件 |

## 验证边界

现有管理员隔离回归XML记录179项通过、0失败、0错误、0跳过，使用实际SQLite ORM、HTTP/JWT和替代依赖；浏览器使用合成响应。扩大数据库范围另有30项因PostgreSQL连接被拒绝而准备报错，不能计作通过。本轮仅核对已有记录与文档，不重跑业务验证。

SQLite唯一性或模拟并发不能代替PostgreSQL行锁竞争。真实Redis、账号联调、PostgreSQL业务库升级、负载测试、学校人工验收和生产部署仍未完成；详见[测试指南](TESTING.md)。

# 党建智能体问答质量约定

## 回答类型

- **制度依据**：回答中的结论带 `[n]` 引用，引用来自当前有效的授权制度文件。
- **制度依据 + 本人情况**：制度回答同时参考了当前账号本人的档案、流程记录或个人材料。
- **本人资料**：只回答“我是谁、我的阶段、我的支部”等本人事实，不冒充制度依据。
- **办理参考**：知识库没有可引用依据，只给通用工作思路，不附引用。
- **拒答**：涉密、引用核验不通过、来源不权威或已失效，明确说明原因和下一步。

## 依据层级

1. 制度知识库：只有正式制度、上级文件和已审核发布的学校文件可以进入引用。
2. 本人情况：本人档案、基本信息采集表、阶段流转、材料清单、发展程序、待办提醒、培训记录，只用于理解本人情形。
3. 临时附件：只在本次提问中作为背景，不进入知识库，不占引用编号。

## 全量授权信息

问答会按当前账号权限读取：

- 本人档案、基本信息采集表、材料清单、个人材料正文、阶段流转、发展程序、培训、培养记录、学习记录、组织生活参加记录、待办提醒；
- 管理角色还会读取授权范围内的组织统计：档案数量、阶段分布、待核验材料、未办结/逾期提醒、近 90 天组织生活记录数量；
- 组织统计只返回聚合数字，不返回其他党员材料正文或名单；
- 政治审查结论、票决明细等敏感内容不进入云端模型。

## 本人资料边界

- 只读取当前登录账号绑定档案；没有绑定档案时明确提示。
- 不读取其他党员的个人材料。
- 身份证号、手机号、邮箱等统一脱敏。
- 敏感级、涉密级个人材料不参与模型问答，并说明未使用。
- 本人资料正文不写入问答历史，只保存来源名称、类型和版本元数据。
- 政治审查结论、支部大会票决等敏感流程详情不进入问答上下文，避免敏感信息出网。

## 最新文件

系统不会凭模型记忆声称“最新”。最新学习主题、制度或通知必须由管理员审核入库，并带生效日期和版本；没有入库时，问答应提示“暂无已发布的最新依据”，不得编造文号、条款或时限。

## 页面使用引导

- 空状态显示“问制度、问本人、看结果”三步提示；
- 输入框上方提供“查制度 / 问我的情况 / 问三会一课”快捷问题；
- 回答后按回答类型显示下一步建议；
- 页面右上角“使用指南”说明怎么问更准、五类回答标签、本人资料边界和“最新文件”规则。

## 问答验收重点

- 制度题必须有可定位引用；
- 无依据题必须显示“办理参考”或拒答；
- 本人题必须只使用当前账号资料；
- 敏感和越权问题不得调用模型；
- 引用核验失败不得返回为有依据。

# 受控备份与隔离恢复

平台“系统运维 → 备份与恢复”已接入真实维护任务。默认 `BACKUP_API_ENABLED=false`；未启用、缺少工具或未配置独立恢复目标时，页面显示实际能力，拒绝相应操作，不生成成功记录。

## 后端配置

下列配置仅进入后端环境，不放入 `VITE_` 或浏览器配置。连接凭据由运维环境管理。

| 变量 | 用途 |
| --- | --- |
| `BACKUP_API_ENABLED` | 显式启用受控维护，默认关闭 |
| `BACKUP_STORAGE_DIR` | 可写的独立备份目录，禁止符号链接路径 |
| `RESTORE_DATABASE_ADMIN_URL` | 能创建新隔离数据库的 PostgreSQL 管理连接 |
| `RESTORE_REDIS_URL` | 独立、为空的恢复 Redis 目标，不能等于业务 Redis URL |
| `PG_DUMP_BIN`、`PG_RESTORE_BIN` | 可选客户端路径，默认 `pg_dump` / `pg_restore` |
| `PG_CLIENT_CONTAINER` | 可选的既有 PostgreSQL 客户端容器，通过本机 Docker 执行工具 |
| `PG_CLIENT_HOST`、`PG_CLIENT_PORT` | 使用容器客户端时指定容器可达的数据库地址 |

备份沿用应用认证加密和文件密钥配置。生产数据库与 Redis 连接继续执行 TLS、账号最小权限及加密检查；本机测试不替代生产权限验收。

## 接口与执行范围

`GET /api/v1/admin/backups` 返回真实工具能力及最近 100 条持久任务。`POST /api/v1/admin/backups` 接收任务名称、`dedup_key`、明确的 `confirm_maintenance`，以及恢复时的 `source_id`。相同请求编号及参数复用原任务；参数冲突或已有未结束任务返回 409。仅真实平台管理员可执行或下载。

执行时通过 Redis 原子门禁停止新业务请求，等待已有业务与任务退出；维护任务查询继续可用。备份核对数据库前后快照、所有登记原件版本、认证加密原件、审计文件和认证吊销记录，生成认证加密的 `.sealed` 文件。下载使用 `GET /admin/backups/{id}/file`。

恢复只接受后端实际成功的备份，自动创建 `module6_restore_` 前缀的新数据库和任务专用目录。页面不能指定任意数据库、目录、覆盖目标或删除数据。恢复校验密文认证、文件哈希、数据库快照与登记原件完整性。当前业务服务保持原连接，页面不提供切换生产数据库的操作。

隔离数据恢复成功后，恢复库运行账号权限仍须由运维单独配置、复核，页面会明确说明。恢复库、演练目录和独立 Redis 目标保留供核对，不自动清理。进程强制中断、长时间维护、生产容器权限、灾难恢复切换及演练保留策略仍需正式运维环境验收。本轮没有执行发布或生产切换。

# 角色与流程

更新日期：2026-10-23。补充角色沿用用户总览图的红色导航、浅灰工作区、白色卡片、表格和统计布局，按职责调整工作台与菜单。

## 角色与组织范围

| 后端角色 | 范围 | 当前界面 |
| --- | --- | --- |
| system_admin | 平台授权范围 | 平台工作台、租户管理、账号与权限、系统运维、平台配置、安全审计 |
| school_admin | 所属学校 | 学校工作台、组织与党员、党员发展、组织生活、学习教育、考核与统计、校级管理（含本校账号管理） |
| department_admin | 所属院系 | 院系首页、支部概览、范围内名册 / 会议 / 材料 / 办理 |
| branch_secretary | 所属支部 | 支部首页、组织生活、独立纪要审核、材料核验与阶段办理 |
| organizer | 所属支部 | 材料接收、原件下载、名册维护、培养登记、人工发展办理 |
| member | 仅本人 | 教师 / 学生两种人员身份，共用本人档案、材料和问答历史 |
| applicant | 仅本人 | 申请人首页、已登记培养进度、本人档案材料、公开资料问答 |

权限采用参考仓库 app/core/security.py 的角色权限与会话权限的交集。校级账号按参考前端路由限制，不能打开平台开户和租户页面。个人角色不能进入组织名册、知识管理、审核或统计，修改地址仍受入口校验。未知地址显示页面不存在。

教师 / 学生是 person_type，不产生管理权限；管理员也不会默认被标为教师党员。

教师党员、学生党员和入党申请人不再提供“账号设置”或“个人中心”入口。本人服务侧栏保留“本人档案”和“个人材料”，头像菜单显示“个人档案”，进入同一份本人档案；发展阶段、组织关系和业务档案只在该页面展示。这些个人角色访问旧 profile 地址会转到 self-archive；管理角色仍通过头像菜单进入独立个人中心。所有角色均可从头像菜单退出登录。

## 原件提交与接收

个人材料支持标题、分类、说明与文件提交，可刷新后回看。支持 PDF、DOCX、TXT、MD、PNG、JPG / JPEG，拒绝空文件、超限文件和异常文件名。真实模式采用后端上传上限。

演示元数据保存在 localStorage，原件保存在 IndexedDB；没有原件的示例记录禁用下载。同支部组织员可查阅和下载授权原件，其他个人账号看不到。原件不会自动进入模型或知识库。“已提交”和演示查阅记录都不等于正式审批、材料核验或阶段变更。

真实模式按明确的提交人档案请求材料。切换人员会清空旧列表与详情，响应和下载均绑定请求所属档案，失败时不展示前一人的材料。

## 纪要审核

组织员保存纪要后提交审核并填写说明。审核中的纪要只读，提交人不能审核自己的记录。另一位同范围授权人员核对纪要，填写意见后通过或退回。保留修订号、提交人、审核人和意见；旧版本与重复决定被拒绝。退回后可修订重提。

审核通过不等于电子归档。正式归档继续遵循原项目的来源材料、学校确认和效力政策，前端不伪造归档完成。

## 人工发展与账号关联

发展工作台按范围列人，支持材料登记与核验、培养事实、材料核对和阶段历史。阶段办理仅允许相邻下一阶段，要求决定日期、办理依据和人工意见；本人档案同步展示新阶段及登记日期。核验材料不会自动推进阶段。

“关联登录账号”需要明确输入已核实账号，仅关联同组织、同租户的有效党员或申请人。档案或账号已有不同关联时拒绝覆盖，不按同名自动匹配。真实模式使用 PUT /member/roster/{id}/account。

## 平台管理

平台账号可创建限定角色与组织的账号，个人账号可明确关联既有档案。演示新账号使用统一示例密码 123456，不保存真实密码。真实模式创建密码按参考后端 8–72 字节约束，角色和组织有效性由服务端验证。

平台管理员可编辑各类账号信息；学校管理员在本校账号管理中编辑本校账号的姓名、业务角色、组织范围、启停状态及密码，不能跨校或授予平台角色。新密码与确认字段初始为空且隐藏，留空保留密码；演示修改保存加盐校验值，登录改用新密码。当前账号权限和最后一位有效管理员受保护，当前账号改密后重新登录。

租户登记名称、类型、上级，不自动分配账号或权限。审计支持搜索、结果筛选、详情及导出，不展示私有原件正文。

## 当前边界

这是独立前端与接口适配，未连接真实 FastAPI、数据库或大模型。真实鉴权、租户隔离、私有存储、审批和归档仍由参考后端负责；真实模式统计限于当前已加载的授权记录。

推优选拔、民主评议、接转报送、完整电子归档和备份恢复继续保留在原项目，当前交付不宣称全部移植。验证记录见 design-qa.md，截图与角色流程结果位于 docs/screenshots/roles/。
